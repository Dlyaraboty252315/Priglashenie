# Даниял & Гаухар — Беташар

Одностраничное приглашение на беташар.

## Что внутри

- `index.html` — готовая страница, без сборки и зависимостей;
- `assets/music.mp3` — музыка для приглашения;
- `.gitignore` — базовый gitignore.

## Запуск локально

Просто откройте `index.html` в браузере.

Для локального сервера:

```bash
python -m http.server 8080
```

После этого откройте `http://localhost:8080`.

## GitHub

1. Создайте новый публичный репозиторий.
2. Загрузите `index.html`, папку `assets` и `.gitignore`.
3. В GitHub откройте **Settings → Pages**.
4. В разделе **Build and deployment** выберите:
   - Source: **Deploy from a branch**
   - Branch: `main`
   - Folder: `/ (root)`
5. Сохраните настройки. GitHub Pages опубликует сайт автоматически.

## Другой статический хостинг

Проект не требует Node.js, npm, PHP или базы данных. Достаточно загрузить содержимое этой папки как статический сайт.

Подойдут GitHub Pages, Netlify, Vercel, Cloudflare Pages и обычный хостинг с поддержкой статических файлов.

## Важно

Музыка запускается после нажатия на конверт — это сделано специально из-за ограничений автозапуска аудио в браузерах.

Ссылка на адрес ведёт на 2GIS и уже указана в `index.html`.
